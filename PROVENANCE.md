# Provenance and interpretation

These display cells are author-derived projections of three frozen aggregate result files: a matched-comparison result and two overall measurement-result files. The source is pinned by hashes in `MANIFEST.json`; no source-level inputs are included.

TAWOS issue context derives from Tawosi, Alsubaihin, Moussa, and Sarro, *The TAWOS dataset*, DOI 10.5522/04/21308124.v1; dataset paper DOI 10.1145/3524842.3528029. The historical five-class labels come from a SEntiMoji/DeepMoji-based model trained using DEVA-labeled data. They are not a direct rerun of the Java DEVA tool. The independent comparison arm used an ordinary OpenAI API project. The human reference was produced by paper authors A and B, with A adjudicating while blind to the archived historical labels.

This package contains no raw message text, API requests/responses, annotation forms, training data, model assets, or row-level project/issue/sprint datasets. Source access, inspection of these aggregate cells, and input-to-estimate reproduction are distinct capabilities. The latter is not provided here.
